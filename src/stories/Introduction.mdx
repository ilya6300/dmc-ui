# Дизайн-система DMC

Библиотека `@dmc/ui`. В entry приложения один раз подключите стили, затем импортируйте компоненты.

## Быстрый старт

```bash
npm install github:ilya6300/dmc-ui
```

```jsx
import "@dmc/ui/styles.css";
import { Main, Box, ThemeProvider, ThemeSelect } from "@dmc/ui";

export function Page() {
  return (
    <ThemeProvider>
      <Main style={{ minHeight: "100vh", padding: 24 }}>
        <ThemeSelect />
        <Box title="Раздел">…</Box>
      </Main>
    </ThemeProvider>
  );
}
```

## Тема

Обёрните приложение в `ThemeProvider`. На корне: `data-dmc-theme` (палитра из `style.css`). Отступы и метрики — **фиксированные** CSS-токены (`--dmc-spacing`, `--dmc-padding`, …), значения меняются только через `data-dmc-size` (не из JS). Override цветов: проп `colors`.

```jsx
import { useTheme, themes } from "@dmc/ui";

const { theme, setTheme, colors, spacing, sizes } = useTheme();
// colors — палитра; spacing / sizes — read-only снимок из CSS
```

Статический импорт `tokens` — только снимок **светлой** палитры; для другой темы — `useTheme().colors` или `themes[theme]`.

Выбор темы и кастомизация цвета:

```jsx
const [theme, setTheme] = useState("light");
<ThemeProvider
  theme={theme}
  onThemeChange={setTheme}
  colors={{ primary: "#0ea5e9" }}
>
  <ThemeSelect />
</ThemeProvider>
```

## Компоненты

| Компонент | Назначение |
|-----------|------------|
| [Main](?path=/docs/design-system-main--docs) | Обёртка страницы |
| [Layout](?path=/docs/design-system-layout--docs) | Колонка контента с входной анимацией |
| [Box](?path=/docs/design-system-box--docs) | Карточка контента |
| [Container](?path=/docs/design-system-container--docs) | Flex-группировка (колонка / строка) |
| [Button](?path=/docs/design-system-button--docs) | Кнопка |
| [Toggle](?path=/docs/design-system-toggle--docs) | Переключатель |
| [ThemeSelect](?path=/docs/design-system-theme-select--docs) | Выбор системной, светлой, тёмной и серой темы |
| [Icon](?path=/docs/design-system-icon--docs) | Иконка (img или SVG-компонент, light/dark) |
| [SideDrawer](?path=/docs/design-system-side-drawer--docs) | Боковая панель |
| [Input](?path=/docs/design-system-input--docs) | Поле ввода (text / number / key) |
| [Spinner](?path=/docs/design-system-spinner--docs) | Индикатор загрузки (несколько вариантов) |
| [Progress](?path=/docs/design-system-progress--docs) | Прогресс bar / circle |
| [Text](?path=/docs/design-system-text--docs) | Типографика (subt, title, p, li, span) |
| [RadioBtn](?path=/docs/design-system-radio-btn--docs) | Группа chip-кнопок (выбор варианта) |

Палитры: `themes`, `getThemeColors`; legacy-снимок: `tokens` (только light).
