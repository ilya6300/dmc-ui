# Дизайн-система DMC

Библиотека `@dmc/ui`: **только импорт компонентов**, без отдельного CSS. Оформление — inline-стили внутри пакета.

## Быстрый старт

```bash
npm install github:ilya6300/dmc-ui
```

```jsx
import { Box, Main, DashCard } from "@dmc/ui";

export function Page() {
  return (
    <Main style={{ minHeight: "100vh" }}>
      <Box style={{ padding: 24 }}>
        <DashCard>…</DashCard>
      </Box>
    </Main>
  );
}
```

## Компоненты

| Компонент | Назначение |
|-----------|------------|
| [Main](?path=/docs/design-system-main--docs) | Обёртка страницы |
| [Box](?path=/docs/design-system-box--docs) | Корневой layout |
| [DashCard](?path=/docs/design-system-dash-card--docs) | Карточка |
| [Toggle](?path=/docs/design-system-toggle--docs) | Переключатель |
| [SideDrawer](?path=/docs/design-system-side-drawer--docs) | Боковая панель |

Палитра для кастомного контента рядом с ДС: экспорт `tokens` из `@dmc/ui` (те же значения, что в компонентах).
