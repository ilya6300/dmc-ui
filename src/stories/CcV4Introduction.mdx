# CC-V4 — дизайн-система DMC

Библиотека `@dmc/ui` повторяет канон карточки компании v4: обёртка `company-card-v4`, кнопки, soft-таблицы, переключатели, поля ввода и боковые панели.

## Быстрый старт

1. Установите пакет из Git (репозиторий [dmc-ui](https://github.com/ilya6300/dmc-ui)):

```bash
npm install github:ilya6300/dmc-ui
```

Ветка или тег (при необходимости):

```bash
npm install github:ilya6300/dmc-ui#main
```

То же в `package.json`:

```json
"dependencies": {
  "@dmc/ui": "github:ilya6300/dmc-ui"
}
```

2. Подключите стили **один раз** в корне приложения (например `App.css` или `index.js`):

```js
import "@dmc/ui/styles.css";
```

3. Оберните страницу в контейнер **[Box](./?path=/docs/cc-v4-box--docs)** — без него часть токенов и сеток не применится:

```jsx
import { Box } from "@dmc/ui";

export function CompanyListPage() {
  return (
    <Box withMainPage pageVariant="company-list-page-v4">
      {/* header-card, dash-card, списки CcV4SoftList* … */}
    </Box>
  );
}
```

## Компоненты

| Компонент | Назначение |
|-----------|------------|
| [Box](?path=/docs/cc-v4-box--docs) | Контейнер `.company-card-v4` (+ опционально `main-page`, модификатор страницы) |
| [CcV4Button](?path=/docs/cc-v4-button--docs) | Кнопки primary / outline / icon |
| [CcV4Toggle](?path=/docs/cc-v4-toggle--docs) | Переключатель с label и опциональным описанием |
| [CcV4SoftList](?path=/docs/cc-v4-soft-list--docs) | Таблица-список: header / body / row |
| [CcV4Input](?path=/docs/cc-v4-input--docs) | Поле ввода v4 (`site-form-control`) |
| [CcV4SideDrawer](?path=/docs/cc-v4-side-drawer--docs) | Боковая модальная панель |

## Модификаторы страниц (`pageVariant`)

Примеры значений `pageVariant` на `Box` (как в dmc-lk):

- `company-list-page-v4` — каталог компаний / партнёров
- `my-companies-page-v4` — «Мои компании»
- `alert-center-v4` — центр уведомлений
- `reports-page-v4` — отчёты

Дополнительные классы можно передать через `className`.
